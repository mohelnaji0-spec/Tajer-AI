# تاجر AI - Tajer AI ✨

**كاتب الإعلانات بالذكاء الاصطناعي باللهجات العربية**

تاجر AI هو موقع يساعد أصحاب المتاجر والمسوقين على إنشاء إعلانات احترافية باستخدام الذكاء الاصطناعي.  
يقوم بإنشاء 3 نسخ إعلانية مختلفة للمنتج باللهجة السودانية والسعودية والمصرية والإماراتية خلال ثوانٍ.

---

## 🚀 المميزات

- ⚡ إنشاء إعلانات بسرعة باستخدام الذكاء الاصطناعي
- 📝 توليد 3 نسخ إعلانية مختلفة
- 🇸🇩 دعم اللهجة السودانية
- 🇸🇦 دعم اللهجة السعودية
- 🇪🇬 دعم اللهجة المصرية
- 🇦🇪 دعم اللهجة الإماراتية
- 📋 نسخ الإعلان بضغطة واحدة
- 🖼️ إنشاء صورة AI للمنتج
- 🔥 نظام مجاني: 10 طلبات يومياً لكل مستخدم
- 💾 حفظ عداد الاستخدام عبر Vercel KV
- 📱 تصميم مناسب للجوال
